## Комплексное задание по Лекции 6: Массивы 

---

### Часть 1. Индексные массивы 

Дан массив участников забега:

php

```php
<?php
$runners = ["Иван" => 24.5, "Мария" => 21.3, "Пётр" => 28.1, "Анна" => 22.8, "Олег" => 19.9];
```

1. Выведи всех участников через `foreach` в формате `"Имя — время мин."`.
2. Через ручной перебор (без `min()`/`max()`) найди **победителя** (наименьшее время) — заведи переменные-аккумуляторы `$bestName` и `$bestTime`.
3. Посчитай **среднее время** всех участников (сумма / `count()`).
4. Добавь в массив шестого участника через `$runners["Имя"] = время;`.
5. Удали из массива участника с самым большим временем через `unset()`.

### Часть 2. Ассоциативные массивы и проверки

Дан профиль пользователя:

php

```php
<?php
$user = [
    "name" => "Дарья",
    "age" => 24,
    "email" => null,
    "city" => "Новосибирск",
];
```

1. Проверь через `isset()`, установлен ли `email`. Объясни результат.
2. Проверь через `array_key_exists()` то же самое. Сравни с предыдущим пунктом.
3. Используя `??`, выведи email или текст `"не указан"`.
4. Добавь ключ `"phone"`, которого раньше не было, и снова сравни поведение `isset()` и `array_key_exists()` для него **до** и **после** добавления.
5. Через `array_keys()` и `array_values()` выведи отдельно все ключи и все значения массива `$user`.

### Часть 3. Многомерный массив — каталог товаров 

php

```php
<?php
$products = [
    ["name" => "Клавиатура", "price" => 2300, "qty" => 4, "category" => "Периферия"],
    ["name" => "Монитор",    "price" => 15400, "qty" => 2, "category" => "Экраны"],
    ["name" => "Мышь",       "price" => 890,  "qty" => 10, "category" => "Периферия"],
    ["name" => "Наушники",   "price" => 3200, "qty" => 0,  "category" => "Аудио"],
    ["name" => "Веб-камера", "price" => 1750, "qty" => 3,  "category" => "Периферия"],
];
```

1. Через `foreach` выведи список: `"Название (категория) — цена руб., в наличии: количество шт."`
2. Посчитай **общую стоимость склада** — сумму `price * qty` по всем товарам.
3. Через `foreach` посчитай, **сколько товаров** относится к категории `"Периферия"`.
4. Найди товар с **нулевым остатком** (`qty === 0`) и выведи только его название.
5. Добавь в каждый товар новый ключ `"totalValue"` = `price * qty` (переберите массив по ссылке `foreach ($products as &$product)`, не забудьте `unset($product)` после цикла!).

### Часть 4. Строки и массивы вместе 

php

```php
<?php
$csvLine = "Смирнов,Инженер,85000;Козлова,Дизайнер,72000;Петров,Менеджер,68000";
```

Это одна строка, где записи разделены `;`, а поля внутри записи — `,`.

1. Через `explode(";", ...)` разбей строку на отдельные записи.
2. Через `foreach` и ещё один `explode(",", ...)` разбери каждую запись на имя, должность и зарплату.
3. Собери из этих данных **новый ассоциативный многомерный массив** вида:

php

```php
[
    ["name" => "Смирнов", "position" => "Инженер", "salary" => 85000],
    // ...
]
```

4. Посчитай через `foreach` общую сумму зарплат.
5. Собери через `implode()` строку вида `"Смирнов | Козлова | Петров"` — только имена, через разделитель `" | "`.

### Часть 5. Итоговая интеграция — отчёт заказа 

Собери всё пройденное в одну законченную программу.

**Условия:**

php

```php
<?php
$order = [
    "customer" => "ООО Ромашка",
    "items" => [
        ["name" => "Бумага А4", "price" => 250, "qty" => 20],
        ["name" => "Ручки", "price" => 15, "qty" => 50],
        ["name" => "Папки", "price" => 45, "qty" => 30],
        ["name" => "Степлер", "price" => 320, "qty" => 5],
    ],
    "discountCode" => null,
];

const BULK_DISCOUNT_THRESHOLD = 10; // если qty >= этого числа — доп. скидка на позицию
const BULK_DISCOUNT_PERCENT = 5;
const DELIVERY_FREE_FROM = 10000;
const DELIVERY_COST = 400;
```

**Нужно вывести отчёт, в котором:**

1. Список позиций заказа: `"Название — количество шт. × цена = сумма"`.
2. Для каждой позиции — если `qty >= BULK_DISCOUNT_THRESHOLD`, применить скидку `BULK_DISCOUNT_PERCENT`% именно к этой позиции (используй тернарный оператор из Лекции 3).
3. Итоговую сумму заказа **с учётом** позиционных скидок.
4. Стоимость доставки: `0`, если итоговая сумма ≥ `DELIVERY_FREE_FROM`, иначе `DELIVERY_COST`.
5. Финальную сумму к оплате (заказ + доставка).
6. Через `??` — вывести код скидки или `"промокод не применён"` (в данных он `null`).
7. Название компании-клиента и количество позиций в заказе (`count()`).
8. Найди вручную (без `max()`) **самую дорогую по сумме** позицию заказа (не по цене за штуку, а по `price * qty`), выведи её название.
