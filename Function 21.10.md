
### Часть 1. Зачем нужны функции

Функция — это именованный блок кода, который можно вызывать много раз. Она решает три задачи:

- **Убирает повторение:** один раз написал, вызываешь где угодно.
- **Даёт имя действию:** `calculateTotal($cart)` читается лучше, чем десять строк вычислений.
- **Изолирует логику:** внутри функции свои переменные, они не мешают остальному коду.

Ты уже пользовался десятками встроенных функций: `count()`, `implode()`, `round()`, `var_dump()`. Теперь научимся писать свои.

### Часть 2. Объявление и вызов

php

```php
<?php
function sayHello() {
    echo "Привет!";
}

sayHello(); // Привет!
sayHello(); // Привет! — можно вызывать сколько угодно раз
```

**Правила имени:** такие же, как у переменных, но **без `$`**. Принято `camelCase`: `calculateTotal`, `getUserName`.

**Важная особенность PHP:** функцию можно вызвать до того, как она объявлена в файле (PHP читает объявления заранее). Но для читаемости принято объявлять функции выше места вызова.

php

```php
<?php
echo greet(); // работает, хотя объявлена ниже

function greet() {
    return "Привет!";
}
```

> Исключение: функции, объявленные внутри условий (`if`) или других функций, существуют только после выполнения этого блока. Такое встречается редко.

### Часть 3. Аргументы (параметры)

php

```php
<?php
function greetUser($name) {
    echo "Привет, $name!";
}

greetUser("Анна");  // Привет, Анна!
greetUser("Иван");  // Привет, Иван!
```

Терминология, которую стоит различать:

- **Параметр** — переменная в объявлении функции (`$name`)
- **Аргумент** — реальное значение, которое передаём при вызове (`"Анна"`)

#### Несколько параметров

php

```php
<?php
function add($a, $b) {
    return $a + $b;
}

echo add(5, 3); // 8
```

#### Значения по умолчанию

php

```php
<?php
function greet($name, $greeting = "Привет") {
    return "$greeting, $name!";
}

echo greet("Анна");              // Привет, Анна!
echo greet("Анна", "Добрый день"); // Добрый день, Анна!
```

Параметры со значением по умолчанию принято ставить **в конец списка**.

#### Именованные аргументы (PHP 8+)

Можно передавать аргументы по имени, в любом порядке:

php

```php
<?php
function createUser($name, $age = 18, $city = "Не указан") {
    return "$name, $age лет, город: $city";
}

echo createUser(name: "Олег", city: "Минск");
// Олег, 18 лет, город: Минск — пропустили $age, он взял значение по умолчанию
```

Это особенно удобно, когда у функции много необязательных параметров.

#### Переменное число аргументов (variadic)

php

```php
<?php
function sum(...$numbers) {
    $total = 0;
    foreach ($numbers as $n) {
        $total += $n;
    }
    return $total;
}

echo sum(1, 2, 3);        // 6
echo sum(10, 20, 30, 40); // 100
```

`...$numbers` собирает все переданные аргументы в массив.

Обратная операция — **распаковка массива** в аргументы:

php

```php
<?php
$nums = [5, 10, 15];
echo sum(...$nums); // 30
```

### Часть 4. Возврат значений: return

php

```php
<?php
function multiply($a, $b) {
    return $a * $b;
}

$result = multiply(4, 5); // 20
echo $result;
```

**Что важно знать про `return`:**

1. **Он завершает функцию немедленно.** Всё, что написано после, не выполнится:

php

```php
<?php
function test() {
    return "Первое";
    echo "Это никогда не выведется";
}
```

2. **Функция без `return` возвращает `null`:**

php

```php
<?php
function noReturn() {
    $x = 5;
}
var_dump(noReturn()); // NULL
```

3. **`echo` и `return` — это разные вещи.** `echo` выводит текст на экран, `return` отдаёт значение вызывающему коду. Новички часто путают.

php

```php
<?php
function addEcho($a, $b) { echo $a + $b; }
function addReturn($a, $b) { return $a + $b; }

$x = addReturn(2, 3) * 10; // 50 — результат можно использовать дальше
$y = addEcho(2, 3) * 10;   // выведет 5, а $y = 0 (null * 10)
```

**Правило:** функции, которые что-то считают, должны **возвращать** результат, а не выводить. Выводить будет код, который их вызвал.

#### Ранний возврат (early return)

Очень полезный приём — выходить из функции сразу, как только ответ понятен. Он убирает вложенные `if`:

php

```php
<?php
// Плохо: вложенность растёт
function getDiscount($age) {
    if ($age >= 0) {
        if ($age < 18) {
            return 10;
        } else {
            if ($age >= 65) {
                return 20;
            } else {
                return 0;
            }
        }
    } else {
        return 0;
    }
}

// Хорошо: проверяем и сразу выходим
function getDiscountBetter($age) {
    if ($age < 0)   return 0;
    if ($age < 18)  return 10;
    if ($age >= 65) return 20;
    return 0;
}
```

#### Возврат нескольких значений

Функция может вернуть только одно значение, но это может быть массив:

php

```php
<?php
function getMinMax($numbers) {
    return [min($numbers), max($numbers)];
}

[$min, $max] = getMinMax([5, 2, 9, 1, 7]);
echo "Мин: $min, макс: $max"; // Мин: 1, макс: 9
```

Здесь пригодилась деструктуризация из Лекции 6.

### Часть 5. Типизация параметров и возвращаемых значений

В PHP 8 хорошим тоном считается указывать типы:

php

```php
<?php
function add(int $a, int $b): int {
    return $a + $b;
}

echo add(5, 3); // 8
```

- `int $a` — тип параметра
- `: int` после скобок — тип возвращаемого значения

#### Доступные типы

|Тип|Что принимает|
|---|---|
|`int`, `float`, `string`, `bool`|скалярные значения|
|`array`|массив|
|`callable`|функцию (анонимную или по имени)|
|`mixed`|что угодно|
|`void`|функция ничего не возвращает (только для возвращаемого типа)|
|`?int`|`int` или `null`|
|`int\|string`|либо то, либо другое (union type, PHP 8+)|

php

```php
<?php
function printLine(string $text): void {
    echo $text . "<br>";
}

function findUser(int $id): ?string {
    return $id === 1 ? "Анна" : null; // может вернуть строку или null
}

function formatId(int|string $id): string {
    return "ID-" . $id;
}
```

#### Что делает PHP при несовпадении типов

Зависит от режима. По умолчанию PHP **пытается привести тип сам**:

php

```php
<?php
function double(int $n): int {
    return $n * 2;
}

echo double("5"); // 10 — строка "5" молча превратилась в int
```

Чтобы включить **строгий режим** (ошибка вместо приведения), в самом начале файла добавляют:

php

```php
<?php
declare(strict_types=1);

function double(int $n): int {
    return $n * 2;
}

echo double("5"); // TypeError: ожидался int, передана string
```

Строгий режим считается хорошей практикой: он ловит ошибки там, где иначе PHP тихо «угадал» бы за тебя. В современных проектах и фреймворках его включают почти всегда. Мы с этого момента тоже будем его использовать.

### Часть 6. Области видимости (scope)

Это одна из самых важных тем лекции.

#### Локальная область

Переменные, созданные внутри функции, **существуют только внутри неё**:

php

```php
<?php
function test() {
    $local = "Я внутри";
    echo $local; // работает
}

test();
echo $local; // Warning: Undefined variable $local
```

#### Внешние переменные внутри функции НЕ видны

В отличие от многих языков, PHP **не даёт функции доступ к внешним переменным**:

php

```php
<?php
$tax = 0.2;

function calculate($price) {
    return $price * $tax; // Warning: Undefined variable $tax
}
```

Это сделано специально: функция должна зависеть только от того, что ей передали. Тогда её поведение предсказуемо.

**Правильное решение — передать значение параметром:**

php

```php
<?php
$tax = 0.2;

function calculate(float $price, float $tax): float {
    return $price * $tax;
}

echo calculate(1000, $tax); // 200
```

#### Ключевое слово global (знать нужно, использовать не стоит)

php

```php
<?php
$counter = 0;

function increment() {
    global $counter;
    $counter++;
}

increment();
increment();
echo $counter; // 2
```

Работает, но считается **плохой практикой**: функция становится зависимой от «внешнего мира», её сложно тестировать и легко сломать. Ты встретишь `global` в старом коде. В своём лучше его избегать.

Есть и массив `$GLOBALS`, который делает то же самое. К нему применимы те же замечания.

#### Константы видны везде

Константы (`const`, `define`) доступны в любой области видимости, в том числе внутри функций:

php

```php
<?php
const TAX = 0.2;

function calculate(float $price): float {
    return $price * TAX; // работает
}
```

Поэтому для неизменяемых настроек константы — хороший вариант.

#### Статические переменные

Обычная локальная переменная «забывается» после каждого вызова. Статическая — **запоминает значение между вызовами**:

php

```php
<?php
function counter() {
    static $count = 0;
    $count++;
    return $count;
}

echo counter(); // 1
echo counter(); // 2
echo counter(); // 3
```

Инициализация `= 0` выполняется только один раз, при первом вызове.

### Часть 7. Передача по значению и по ссылке

По умолчанию PHP передаёт аргументы **по значению**: функция получает копию, оригинал не меняется.

php

```php
<?php
function addOne(int $n): void {
    $n++;
}

$x = 5;
addOne($x);
echo $x; // 5 — не изменилось
```

Чтобы функция могла менять оригинал, используют **передачу по ссылке** (`&`):

php

```php
<?php
function addOne(int &$n): void {
    $n++;
}

$x = 5;
addOne($x);
echo $x; // 6
```

Тот же знак `&` ты видел в `foreach ($arr as &$item)`.

**Когда это используют:** для функций, которые должны изменить переданный массив на месте. Например, встроенная `sort()` принимает массив по ссылке, поэтому она меняет его, а не возвращает новый.

> Совет: по возможности лучше **возвращать новое значение**, чем менять аргумент по ссылке. Такой код проще читать и отлаживать.

### Часть 8. Анонимные функции и замыкания

С анонимными функциями ты уже работал в Лекции 7. Теперь разберём их правильно.

#### Анонимная функция

php

```php
<?php
$greet = function (string $name): string {
    return "Привет, $name!";
};

echo $greet("Анна");
```

После закрывающей скобки обязательна `;`, потому что это присваивание.

#### Ключевое слово use

Обычная анонимная функция, как и обычная, не видит внешние переменные. Чтобы «захватить» их, используется `use`:

php

```php
<?php
$tax = 0.2;

$calculate = function (float $price) use ($tax): float {
    return $price * (1 + $tax);
};

echo $calculate(1000); // 1200
```

Функция, которая захватила переменные из внешней области, называется **замыканием** (closure).

**Важно:** `use` захватывает значение **в момент создания** функции. Если потом изменить `$tax`, функция этого не увидит:

php

```php
<?php
$tax = 0.2;
$calc = function ($price) use ($tax) { return $price * (1 + $tax); };

$tax = 0.5; // изменили позже
echo $calc(1000); // всё равно 1200
```

Чтобы видеть изменения, захватывают по ссылке: `use (&$tax)`.

#### Стрелочные функции

В Лекции 7 мы говорили, что `fn` автоматически видит внешние переменные. Теперь понятно, почему это удобно:

php

```php
<?php
$tax = 0.2;

$calc = fn(float $price): float => $price * (1 + $tax); // use не нужен
echo $calc(1000); // 1200
```

Стрелочная функция захватывает **по значению**, и только в однострочной форме (одно выражение после `=>`).

#### Функции как значения

Функцию можно передавать как аргумент, возвращать из другой функции, хранить в массиве:

php

```php
<?php
function applyTwice(callable $fn, int $value): int {
    return $fn($fn($value));
}

echo applyTwice(fn($x) => $x * 3, 2); // 18  (2 → 6 → 18)
```

php

```php
<?php
function makeMultiplier(int $factor): callable {
    return fn($x) => $x * $factor;
}

$double = makeMultiplier(2);
$triple = makeMultiplier(3);

echo $double(10); // 20
echo $triple(10); // 30
```

Именно так устроены `array_map`, `array_filter` и `usort`: они принимают `callable`.

### Часть 9. Рекурсия

Рекурсия — это когда функция вызывает саму себя. У неё всегда должно быть два элемента:

1. **Базовый случай** — условие, при котором рекурсия останавливается
2. **Рекурсивный шаг** — вызов себя с «упрощённым» аргументом

Классический пример — факториал (`5! = 5 × 4 × 3 × 2 × 1`):

php

```php
<?php
function factorial(int $n): int {
    if ($n <= 1) {
        return 1; // базовый случай
    }
    return $n * factorial($n - 1); // рекурсивный шаг
}

echo factorial(5); // 120
```

Как это раскручивается:

```
factorial(5) = 5 * factorial(4)
             = 5 * 4 * factorial(3)
             = 5 * 4 * 3 * factorial(2)
             = 5 * 4 * 3 * 2 * factorial(1)
             = 5 * 4 * 3 * 2 * 1 = 120
```

**Опасность:** без базового случая функция будет вызывать себя бесконечно, пока не закончится память.

**Где рекурсия полезна:** обход вложенных структур неизвестной глубины, например дерево категорий или вложенные папки:

php

```php
<?php
function sumNested(array $data): int {
    $total = 0;
    foreach ($data as $item) {
        $total += is_array($item) ? sumNested($item) : $item;
    }
    return $total;
}

echo sumNested([1, [2, 3], [4, [5, 6]]]); // 21
```

### Часть 10. Документирование функций

Для сложных функций принято писать комментарий в формате **PHPDoc**. Редакторы (в том числе VS Code с Intelephense) используют его для подсказок:

php

```php
<?php
/**
 * Считает итоговую цену с учётом скидки.
 *
 * @param float $price   Исходная цена
 * @param int   $percent Скидка в процентах (0-100)
 * @return float         Цена после скидки
 */
function applyDiscount(float $price, int $percent): float {
    return $price * (100 - $percent) / 100;
}
```
