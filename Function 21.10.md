Задание по Лекции 8: функции без классов

Здесь другая тема, чем в прошлом задании: мини-банк, построенный только на функциях и замыканиях. Работай в файле bank-functions.php. В начале файла declare(strict_types=1);, везде указывай типы.

Правила:

Функции не выводят текст через echo, а возвращают результат.
global не использовать.
Встроенные функции можно, если задание прямо не запрещает.

Часть 1. Базовые функции
Напиши isPositive(int|float $n): bool. Проверь на 5, -3, 0, 0.5.
Напиши normalizeAccount(string $raw): string, которая превращает любой из вариантов " acc 100 ", "ACC100", "acc-100" в "ACC-100". Подсказка: очисти строку регуляркой, оставь буквы и цифры, затем собери результат заново.
Напиши signedAmount(array $tx): float, которая возвращает сумму со знаком: плюс для deposit, минус для withdraw. Используй match. Для неизвестного типа функция должна выбросить исключение: throw new InvalidArgumentException("Неизвестный тип: ..."). Что именно происходит при throw, мы подробно разберём в Лекции 15, пока считай это «аварийной остановкой с сообщением».
Напиши isWithdrawal(array $tx): bool и isDeposit(array $tx): bool. Они понадобятся в следующих частях.
Часть 2. Аргументы и возвращаемые значения
Напиши calculateBalance(array $transactions, string $account, float $initial = 0.0): float. Баланс считается как начальный остаток плюс сумма всех операций счёта со знаком. Проверь для всех трёх счетов.
Напиши getLastTransaction(array $transactions, string $account): ?array, которая возвращает последнюю по дате операцию счёта или null, если операций нет. Проверь на ACC-100 и на несуществующем ACC-999.
Напиши createTransaction(string $account, string $type, float $amount, ?string $date = null, string $note = ""): array. Если дата не передана, подставь сегодняшнюю через date('Y-m-d'). Создай три транзакции: с позиционными аргументами, с пропуском даты и указанием заметки через именованные аргументы, и в перемешанном порядке аргументов.
Напиши mergeTransactions(array ...$lists): array, которая принимает любое число списков операций, объединяет их и сортирует по дате. Вызови её с двумя списками, а потом передай массив списков через распаковку ....
Напиши sumBy(array $items, string $key): float, которая суммирует значения по указанному ключу. Проверь на ключе "amount".
Часть 3. Замыкания-фабрики
Напиши makeFeeCalculator(float $percent, float $min = 0.0): callable. Возвращаемая функция принимает сумму и считает комиссию в процентах, но не меньше $min. Создай два калькулятора: 1.5% с минимумом MIN_FEE и 0.5% без минимума. Проверь оба на суммах 100 и 10000.
Напиши makeDailyLimiter(float $limit): callable. Возвращаемая функция принимает сумму снятия и:
возвращает true и запоминает потраченное, если общая сумма не превышает лимит;
возвращает false и ничего не запоминает, если лимит был бы превышен.
Для хранения потраченной суммы используй use (&$spent). Проверь на последовательности 10000, 15000, 7000, 5000, 100. Объясни в комментарии, почему здесь нужна ссылка, а use ($spent) не сработает.
Создай два независимых лимитера (для двух разных клиентов) и покажи, что их счётчики не влияют друг на друга.
Напиши makeCounter(int $start = 0, int $step = 1): array, которая возвращает массив из трёх замыканий: next, reset и current. Все три работают с общей переменной через use (&$value).
php
   $c = makeCounter(10, 5);
   $c["next"]();    // 15
   $c["next"]();    // 20
   $c["current"](); // 20
   $c["reset"]();
   $c["current"](); // 10
Часть 4. Функции высшего порядка
Напиши compose(callable ...$fns): callable, которая возвращает функцию, применяющую переданные функции слева направо. Результат первой становится аргументом второй и так далее.
Собери с её помощью обработчик строки из встроенных функций через синтаксис первого класса (PHP 8.1):
php
   $clean = compose(trim(...), mb_strtolower(...), fn($s) => preg_replace('/\s+/u', ' ', $s));

Проверь на строке " ПРИВЕТ Мир ". Объясни в комментарии, что делает запись trim(...).
3. Напиши partial(callable $fn, mixed ...$fixed): callable, которая «фиксирует» первые аргументы функции. Например, partial('str_replace', "кот", "пёс") вернёт функцию, которой достаточно передать только строку.
4. Напиши pluck(array $items, string $key): array, которая достаёт из списка массивов значения по одному ключу. Реализуй её через array_map.
5. Напиши groupBy(array $items, callable $keyFn): array, которая группирует элементы по значению, которое возвращает $keyFn. Сгруппируй транзакции по счёту, а потом по типу операции.
6. Напиши pipeline(array $data, callable ...$steps): array, которая последовательно пропускает массив через шаги. Собери конвейер: только списания, дороже 1000, отсортированные по сумме по убыванию, только поле amount.

Часть 5. Статические переменные и мемоизация

Напиши callCounter(): int, которая при каждом вызове возвращает, сколько раз её вызывали. Затем покажи на примере, чем статическая переменная отличается от обычной локальной.
Напиши обычную рекурсивную функцию fib(int $n): int и добавь в неё статический счётчик вызовов. Подсчитай, сколько вызовов потребовалось для fib(20).
Напиши memoize(callable $fn): callable, которая возвращает версию функции с кэшем результатов (кэш хранится в массиве через use (&$cache)). Ключ кэша строй из аргументов через serialize($args) или implode.
Напиши fibMemo(int $n): int с кэшем в статической переменной-массиве, и сравни число вызовов с версией из пункта 3 для n = 30. Объясни разницу в комментарии.
Часть 6. Рекурсия
Напиши flatten(array $data): array, которая превращает вложенный массив любой глубины в плоский:

Напиши binarySearch(array $sorted, int $target, int $low = 0, ?int $high = null): int. Она возвращает индекс найденного элемента или -1. Реализуй рекурсивно. Проверь на отсортированном массиве, включая первый и последний элементы, отсутствующее число и пустой массив.
Напиши hanoi(int $n, string $from = "A", string $to = "C", string $via = "B"): array, которая возвращает список ходов ханойской башни вида "A → C". Для n = 3 должно получиться 7 ходов. Для n = 10 проверь, что число ходов равно 2^10 - 1.

Часть 8. Найди ошибки

В этом коде шесть ошибок. Найди их все, объясни каждую в комментарии и исправь.

php
<?php
declare(strict_types=1);

function average(array $numbers): float {
    $sum = 0;
    foreach ($numbers as $n) {
        $sum += $n;
    }
    return $sum / count($numbers);
}

function addTax(float $price, float $tax = 0.2): float {
    $price * (1 + $tax);
}

function findUser(array $users, int $id): array {
    foreach ($users as $u) {
        if ($u["id"] === $id) {
            return $u;
        }
    }
    return null;
}

function counter(): int {
    $count = 0;
    return ++$count;
}

function total(float $price, float $discount = 0.0, float $tax): float {
    return ($price - $discount) * (1 + $tax);
}

$rate = 0.2;
function withRate(float $price): float {
    return $price * $rate;
}

После исправления вызови каждую функцию и убедись, что результат соответствует ожиданиям. Для average([]) реши сам, что должна возвращать функция, и обоснуй выбор.

Часть 9. Итог: банковская выписка

Собери всё в одну программу.

Напиши buildStatement(array $transactions, string $account, float $initial, callable $feeFn): array, которая возвращает массив с ключами:

account: нормализованный номер счёта;
lines: список операций счёта по датам; у каждой есть date, type, amount, fee (комиссия только для списаний, для пополнений 0.0) и balance (баланс после операции с учётом комиссии);
totalDeposits: сумма пополнений;
totalWithdrawals: сумма списаний;
totalFees: сумма комиссий;
finalBalance: итоговый баланс;
rejected: операции, которые лимитер отклонил (используй makeDailyLimiter(DAILY_LIMIT) для списаний; отклонённая операция не влияет на баланс).

Затем напиши renderStatement(array $statement): string, которая превращает массив в готовый текст. Используй sprintf(), number_format() и str_repeat(). Суммы выводи в формате "12 345,67".

Основной код должен сводиться к минимуму:

php
$feeFn = makeFeeCalculator(1.5, MIN_FEE);
$statement = buildStatement($transactions, "acc 100", 1000.0, $feeFn);
echo "<pre>" . renderStatement($statement) . "</pre>";
